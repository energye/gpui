# 待解决问题定义书：文本输入框闪烁/上屏慢/补丁清理（2026-09-08）

> 用途：新会话重修的唯一问题输入。只定义“要解决什么、怎么算修好”，
> 不记录任何已回滚的改法（改法存档见 `docs/REWRITE_ROUND_NOTES.md`，
> 背景地图见 `docs/RETAINED_DEFAULT_AUDIT.md`）。
> 复现一律用 `examples/ui_text_edit_accept`（1200×800，retained 省帧默认）。

## 问题一：界面闪（最高优）

- 现象：真窗直播偶发单帧或连续几帧变暗——背景压黑、亮色文字不动，
  几十毫秒后自行恢复。抓屏统计里 120–200 连抓出现 2%–17% 不等，
  爱跟在光标翻转附近，但毫秒级引擎日志显示出事帧的决策
  （清还是留、损伤多大、录了几个纹理）和前后正常帧一字一样。
- 复现：开窗 → 点 A 框获焦 → 打几个字 → `xwd -id <win>连抓 ≥120 帧 →
  逐帧算平均亮度，找相对中位数掉一半（约 66→34）的帧。
  未获焦静置 120 帧曾全绿，可作对照。
- 已知线索（未定罪）：录制和主上屏共用会话里的纹理绑定槽，
  背景大纹理可能被踩（字走字形管线所以没事）；合成器/抓屏竞态尚未排除。
- 修好标准：获焦闪烁状态下 200 连抓零异常帧；且下面问题二、三的验收同时过。

## 问题二：输入上屏慢

- 现象：点框获焦后打字，字上屏有可感知的延迟。
- 复现：A 框获焦后注入 `hi`（十进制 keysym 104/105），150ms 内抓帧应见首字，
  750ms 内抓帧应见全字。
- 已知线索：A 框 882×42 区域曾每帧重录（稳态 `dirty=2` 恒脏，光栅被堵），
  嫌疑链：边框 `OnPaint` 里挪光标（画一次脏一次）、`MoveTo` 同值也标脏、
  包壳盒子脏标记清不掉（`baseOf` 名单认不出包壳类型，一次变脏脏一辈子）。
- 修好标准：复现通过；且稳态无交互时连看 DirtyLayerIDs，大部分帧应为零脏；
  6 秒快照 `paint_count` 应为个位数。
