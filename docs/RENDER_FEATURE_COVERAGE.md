## 0. 判定口径

| 判定 | 含义 |
|---|---|
| ✅ | 有真窗直用（某个真窗的示例源码里直接调用该 API） |
| 🔁 | 无示例直调，但有间接路径（ui/ 或 engine/ 层在调用，真窗经该层执行到它） |
| 📄 | 仅离屏出图示例（render_*/text_langs_png 产 PNG，不是真窗） |
| ⛔ | 无任何真窗/示例消费者（仅单测、仅库内自用、或全仓零调用） |

> `✅` 只表示有真窗直用，不等于生产接线；生产/原子验证口径见 `RENDER_API_CATALOG.md` 的状态词（🔗 生产接线 / 🔌 无生产消费者）。
