# P2.4d 真窗补充：桌面 X11 :1 单窗复核（R20）
# 目的：headless Wayland 下 R20 的 hitch 92/min 是环境性；用同一二进制在 X11 复跑，
#       证明池数字跨环境一致，窗自身只剩 P1.4 基线同款的 scripted=4/5 红。
# 安全：当前桌面只跑单窗、一轮一窗；RUN_SECONDS 自己退出（标准关闭），未发 kill；
#       每轮前后查 X :1 存活。

## 环境
- DISPLAY=:1（桌面 X11，非隔离批量环境）
- binary: /tmp/p24d-bin/ui_wr_r20_filter（window-gates.sh 预编译，HEAD ac2e58b3 + P2.4d 工作区）
- R20_SNAP_DIR=docs/render_gpu_converge/evidence/P2.4d/r20_snapshots_x11

## 命令
env -u WAYLAND_DISPLAY DISPLAY=:1 \
  R20_SNAP_DIR="$PWD/docs/render_gpu_converge/evidence/P2.4d/r20_snapshots_x11" \
  RUN_SECONDS=30 timeout 120 /tmp/p24d-bin/ui_wr_r20_filter \
  > ui_wr_r20_filter_native-x11.json 2> ui_wr_r20_filter_native-x11.stderr
