## 3 拍板点

1. **真窗重放显示环境**：推荐 **P1.4 同款 :3 rootless Xwayland**（与基线同环境，对账最干净；14 窗 x11grab 环境红维持「环境红」登记不粉饰）。备选：隔离真 Xorg（C1 归 P2.6 的「可抓图显示」，14 窗可能转绿，但构成环境差异需逐条登记；且 P1.4 基线的其余窗也在 :3 采的，换环境会引入系统差异）。
2. **I3/I4 顺序**：推荐 **不阻塞重放**——R20 三张探针图在 P1.4 基线就是同状态（I3/I4 行已实证），重放按基线同红对账；诊断放 g 段独立做，结论回写台账。备选：先诊断完再重放（R20 判定口径更干净，但 g 段诊断深度不定，拖住主线）。
3. **执行分批**：推荐 a→b→c→d→e→f→g→h 串行，b/c 两长段后台跑、逐段落证据；每段完成即在台账 §7 记一笔（不攒到最后）。
4. **长跑处置**：P1.3 的 zz_b1_ttf_scan（704s）/zz_b2_bitmap_scan（1256s）/zz_b1_vf（484s）照基线口径跑足，单独 -timeout，不砍。
