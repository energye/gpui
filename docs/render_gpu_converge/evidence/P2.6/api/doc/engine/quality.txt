package quality // import "github.com/energye/gpui/engine/quality"

Package quality carries the quality-tier math every 2.5D play follows.

Frozen 2026-09-16: Level, LevelHigh, LevelMedium, LevelLow, ParseLevel, Spec,
SpecFor, Quality, NewQuality, ParseQuality, LoadQuality, Encode, StoreQuality,
Level, Spec, Equal, Switch. Moved from engine/save in 2026-09-30 (E02); save
keeps only slot/version migration. Additive changes only.

Three tiers, frozen: high maps to 1000 particles plus 8 lights plus scale 1.00,
medium maps to 500 particles plus 4 lights plus scale 0.75, low maps to 200
particles plus 2 lights plus scale 0.50. High is the full-fidelity tier;
medium halves particles and lights and renders at three quarters resolution;
low keeps one fifth of the particles, a quarter of the lights, and renders at
half resolution. The numbers live in engine/quality/testdata/quality_cases.json;
the code only replays them, so tuning a tier means editing that file first.

The caller builds a Quality with New or Parse, reads the frozen Spec with Spec,
and changes tiers with Switch. Switching only replaces the level: the same scene
keeps running, nothing reloads, nothing flashes. Parse levels by design: only
version "1.0" files parse; empty input is InvalidArg, torn shapes are BadData,
foreign or newer versions are VersionMismatch, oversized files are OutOfMemory.
Constructor-style calls (New, ParseLevel) report bad tiers as InvalidArg; file
Parse reports the same bad tier as BadData. Nil receivers report InvalidArg and
change nothing. Only core numbers cross the boundary; render types are converted
at the call site, never here.

File (self JSON, frozen): version "1.0", quality "high"|"medium"|"low".
Unknown fields are ignored so a newer minor file still decodes its tier;
a missing quality is BadData, never a guessed tier.

Quality tiers live here: high/medium/low budgets plus the file codec. Package
doc, frozen list, and tier table live in doc.go.

CONSTANTS

const MaxQualityBytes = 4096
    MaxQualityBytes caps one quality file. Well-formed files beyond the budget
    are OutOfMemory, never a guessed load.


VARIABLES

var QualityVersion = core.Version{Major: 1, Minor: 0}
    QualityVersion is the quality file version every Encode writes. Bump Minor
    for additive fields, Major for a breaking shape.


FUNCTIONS

func StoreQuality(q Quality, path string) error
    StoreQuality writes q to path, creating parent directories. Empty paths
    are InvalidArg; OS failures are NotFound with the cause; tier errors match
    Encode.


TYPES

type Level string
    Level is one frozen quality tier: high, medium, or low.

const (
	LevelHigh   Level = "high"
	LevelMedium Level = "medium"
	LevelLow    Level = "low"
)
    Frozen tier names. Parse is case-sensitive: "HIGH" is rejected so a typo
    never silently lands on another tier.

func ParseLevel(name string) (Level, error)
    ParseLevel maps a tier name to its Level. Empty and unknown names are a core
    InvalidArg error.

func (l Level) String() string
    String returns the tier name.

func (l Level) Valid() bool
    Valid reports whether l is one of the three frozen tiers.

type Quality struct {
	// Has unexported fields.
}
    Quality is the current tier handle: one level plus its frozen spec. The zero
    value holds no tier; New and Parse are the only ways in. Readers never fail
    on a valid handle; writers on nil report InvalidArg and change nothing.

func LoadQuality(path string) (Quality, error)
    LoadQuality reads path as a quality file. Empty paths are InvalidArg,
    missing files are NotFound; the rest matches ParseQuality.

func NewQuality(level Level) (Quality, error)
    New builds a handle on the given tier. Unknown tiers are a core InvalidArg
    error.

func ParseQuality(data []byte) (Quality, error)
    Parse validates file bytes into a Quality. Empty input is InvalidArg,
    size overruns are OutOfMemory, torn JSON and bad tiers are BadData, foreign
    or newer versions are VersionMismatch.

func (q Quality) Encode() ([]byte, error)
    Encode renders the canonical file bytes. A zero handle (no tier) is
    InvalidArg; budget overruns are OutOfMemory. The input is never mutated.

func (q Quality) Equal(o Quality) bool
    Equal reports whether o holds the same tier.

func (q Quality) Level() Level
    Level returns the current tier. A zero handle reports "".

func (q Quality) Spec() Spec
    Spec returns the frozen Spec of the current tier. A zero handle reports the
    zero Spec; valid handles never fail.

func (q *Quality) Switch(to Level) error
    Switch moves the handle to another tier without touching anything else:
    the scene keeps running on the new Spec, nothing reloads. Switching to the
    current tier is a no-op success. Unknown tiers are a core InvalidArg error
    and change nothing. Nil handles report InvalidArg.

type Spec struct {
	// Particles caps live particles (high 1000, medium 500, low 200).
	Particles int
	// Lights caps evaluated lights (high 8, medium 4, low 2).
	Lights int
	// Scale is the render resolution ratio (high 1.00, medium 0.75, low 0.50).
	Scale float64
}
    Spec is the frozen per-tier budget the scene follows: how many particles to
    spawn, how many lights to evaluate, and which resolution ratio to render at.
    Fields stay values so copies never alias.

func SpecFor(l Level) (Spec, error)
    SpecFor returns the frozen Spec of a tier. Unknown tiers are a core
    InvalidArg error.
