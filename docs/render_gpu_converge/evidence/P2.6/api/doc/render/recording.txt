package recording // import "github.com/energye/gpui/render/recording"

Package recording provides types for recording drawing operations.

The recording system enables vector export (PDF, SVG) by capturing drawing
operations as typed command structures instead of immediate rasterization.
Commands are stored in a Recording and can be replayed to any backend.

Design follows Cairo's approach of typed command structs for inspectability and
debuggability, rather than the binary serialization format.

# Architecture

Commands capture all drawing operations:
  - State commands (Save, Restore, Concat, SetClip)
  - Drawing commands (FillPath, StrokePath, FillRect, DrawImage, DrawText)
  - Style commands (SetFillStyle, SetStrokeStyle, SetLineWidth, etc.)

Resources (paths, brushes, images) are stored in a ResourcePool and referenced
by typed handles (PathRef, BrushRef, ImageRef) to enable deduplication and
efficient memory usage.

# Example

    // Record drawing operations
    rec := recording.NewRecorder(800, 600)
    rec.Save()
    rec.SetTransform(matrix)
    rec.FillPath(pathRef, brushRef, FillRuleNonZero)
    rec.Restore()
    r := rec.Finish()

    // Replay to a backend
    r.Playback(pdfBackend)

Package recording provides a command-based drawing recording system for render.

The recording system captures drawing operations as commands that can be
played back to different backends, enabling vector export (PDF, SVG) and other
transformations of 2D graphics.

# Architecture

The system follows a Command Pattern with three main components:

  - Recorder: Captures drawing operations as commands
  - Recording: Stores commands and resources for playback
  - Backend: Renders commands to a specific output format

This design is inspired by the SkPicture and Cairo's recording surface.

# Basic Usage

Record drawing operations using a Recorder:

    rec := recording.NewRecorder(800, 600)

    // Draw using the familiar Context-like API
    rec.SetFillRGBA(1, 0, 0, 1) // Red
    rec.DrawRectangle(100, 100, 200, 150)
    rec.Fill()

    rec.SetStrokeRGBA(0, 0, 1, 1) // Blue
    rec.SetLineWidth(2)
    rec.DrawCircle(400, 300, 50)
    rec.Stroke()

    // Finish recording
    r := rec.FinishRecording()

# Playback to Backends

Play back recordings to different output formats:

    // PDF output (requires github.com/energye/gpui/render-pdf)
    import _ "github.com/energye/gpui/render-pdf"

    pdfBackend, _ := recording.NewBackend("pdf")
    r.Playback(pdfBackend)
    pdfBackend.(recording.FileBackend).SaveToFile("output.pdf")

    // SVG output (requires github.com/energye/gpui/render-svg)
    import _ "github.com/energye/gpui/render-svg"

    svgBackend, _ := recording.NewBackend("svg")
    r.Playback(svgBackend)
    svgBackend.(recording.FileBackend).SaveToFile("output.svg")

    // Raster output (built-in)
    rasterBackend, _ := recording.NewBackend("raster")
    r.Playback(rasterBackend)
    rasterBackend.(recording.PixmapBackend).Pixmap() // Get pixel data

# Backend Registration

Backends are registered using the database/sql driver pattern. Import a backend
package with a blank identifier to automatically register it:

    import (
        "github.com/energye/gpui/render/recording"
        _ "github.com/energye/gpui/render-pdf" // Registers "pdf" backend
        _ "github.com/energye/gpui/render-svg" // Registers "svg" backend
    )

The built-in "raster" backend is always available via:

    import _ "github.com/energye/gpui/render/recording/backends/raster"

# Resource Management

The recording system uses reference-based resource pooling for efficient storage
and playback:

  - Paths are cloned and stored with PathRef references
  - Brushes (solid colors, gradients) are stored with BrushRef references
  - Images are stored with ImageRef references
  - Fonts are stored with FontRef references

This ensures recordings are immutable and can be safely played back multiple
times to different backends.

# Supported Operations

The Recorder supports the full gg drawing API:

  - Path operations: MoveTo, LineTo, QuadraticTo, CubicTo, ClosePath
  - Shape helpers: DrawRectangle, DrawRoundedRectangle, DrawCircle, DrawEllipse,
    DrawArc, DrawEllipticalArc
  - Fill and stroke with solid colors and gradients, each carrying its blend
    mode
  - Line styles: width, cap, join, miter limit, dash patterns
  - Transformations: Translate, Rotate, Scale, matrix operations
  - Clipping: path-based clipping with fill rules
  - State management: Push/Pop (Save/Restore)
  - Text rendering (font-dependent)
  - Image drawing

# Brushes

The recording system supports multiple brush types for fills and strokes:

  - SolidBrush: Single solid color
  - LinearGradientBrush: Linear color gradient
  - RadialGradientBrush: Radial color gradient
  - SweepGradientBrush: Angular/conic gradient

Example gradient usage:

    grad := recording.NewLinearGradientBrush(0, 0, 200, 200).
        AddColorStop(0, render.RGBA{R: 1, G: 0, B: 0, A: 1}).
        AddColorStop(1, render.RGBA{R: 0, G: 0, B: 1, A: 1})

    rec.SetFillStyle(grad)
    rec.Fill()

# Custom Backends

Implement the Backend interface to create custom output formats. The contract is
38 methods — one per command the Recorder can emit; the excerpt below shows the
shape, Backend is the authority:

    type Backend interface {
        Begin(width, height int) error
        End() error
        Save()
        Restore()
        Concat(m Matrix)
        SetClip(path *render.Path, rule FillRule)
        ClipRect(rect Rect)
        FillPath(path *render.Path, brush Brush, rule FillRule, blend render.BlendMode)
        StrokePath(path *render.Path, brush Brush, stroke Stroke, blend render.BlendMode)
        FillRect(rect Rect, brush Brush, blend render.BlendMode)
        DrawImage(img *render.ImageBuf, opts render.DrawImageOptions)
        DrawGlyphs(glyphs []text.ShapedGlyph, face text.Face, x, y float64, colored bool, brush Brush)
        DrawText(s string, x, y float64, face text.Face, brush Brush)
        PushLayer(blend render.BlendMode, opacity float64)
        PopLayer()
        // ... plus the remaining image/mesh/decoration/effect/layer methods
    }

Fill and stroke commands carry the blend mode that was ambient when they were
recorded (Skia draws store their own paint). Replay sets it for that single call
and restores the target canvas' blend afterward, so a DestinationIn fill used by
render.DrawShaderMask cannot leak into later text or image commands.

All geometry arrives in user space under the replayed CTM; backends must not
bake device coordinates in.

Register custom backends with Register:

    func init() {
        recording.Register("myformat", func() recording.Backend {
            return NewMyBackend()
        })
    }

# Thread Safety

Recorder is NOT safe for concurrent use. Each goroutine should use its own
Recorder instance. However, Recording objects are immutable after Finish() and
can be safely shared and played back from multiple goroutines.

# Performance Considerations

The recording system is optimized for:

  - Minimal allocations during recording (pre-allocated slices)
  - Efficient resource deduplication via pooling
  - Fast playback with direct command dispatch

For real-time rendering, prefer direct render.Context usage. Use recording when
you need vector export or command inspection.

FUNCTIONS

func ApplyBrush(dc render.Canvas, brush Brush, fill bool)
    ApplyBrush sets the dc's fill or stroke paint from a recorded brush.

    A recorded pattern brush is replayed as a pattern, not as a brush: an image
    pattern is a render.Pattern (render.Brush is sealed and has no image form),
    and Context.SetFillPattern is what the live call went through, so the
    rebuilt pattern lands in the same paint fields and samples the same texels.
    When the pattern has nothing left to sample — its image was disposed
    between recording and replay — the paint becomes fully transparent instead
    of guessing a colour: painting nothing is the honest degradation, painting
    black is not.

func ApplyStroke(dc render.Canvas, stroke Stroke)
    ApplyStroke copies a recorded stroke style onto the context.

func Backends() []string
    Backends returns a sorted list of registered backend names. The list is
    sorted alphabetically for consistent output.

func Count() int
    Count returns the number of registered backends.

func IsRegistered(name string) bool
    IsRegistered checks if a backend with the given name is registered.

func MaskSkips() int64
    MaskSkips returns how many mask commands playback had to skip. A non-zero
    value means the target could not reproduce the recording's device space (or
    has no mask capability at all); callers that expect masks to be visible must
    treat it as a failure.

func Register(name string, factory BackendFactory)
    Register registers a backend factory with the given name. This function is
    typically called from init() in backend packages, following the database/sql
    driver pattern:

        func init() {
            recording.Register("pdf", func() recording.Backend {
                return NewPDFBackend()
            })
        }

    Register panics if:
      - factory is nil
      - a backend with the same name is already registered

    This ensures that duplicate registrations are caught early during program
    initialization rather than silently overwriting backends.

func ResetMaskSkips()
    ResetMaskSkips zeroes the skip counter (tests / per-window measurement).

func ToRenderBrush(b Brush) render.Brush
    ToRenderBrush converts a recording.Brush back to a render.Brush for playback
    onto a render.Context. Pattern brushes have no render.Brush form at all —
    render.Brush is sealed and an image pattern is a Pattern, not a Brush — so
    they return nil here and replay through ToRenderPattern instead. ApplyBrush
    does that routing; a caller that goes straight to SetFillBrush would paint
    black, which is exactly the degradation this function refuses to hide.

func ToRenderPattern(b Brush) (render.Pattern, bool)
    ToRenderPattern converts a recorded brush back to a render.Pattern for
    playback onto a live context. It returns false for brushes that are not
    patterns (solid, gradient), which the caller replays as brushes. A true with
    a nil Pattern means "this was a pattern, but there is nothing to sample" —
    the recorded image is gone — and the caller must paint nothing rather than
    invent a colour.

func TransformPoint(m Matrix, x, y float64) (float64, float64)
    TransformPoint applies m to (x, y) and returns the transformed coordinates.
    render.Matrix works in render.Point; this keeps the recorder's float-pair
    call sites (and render.Context.TransformPoint's signature) readable.

func Unregister(name string)
    Unregister removes a backend from the registry. This is primarily useful
    for testing to clean up between tests. If the backend is not registered,
    this is a no-op.

type Backend interface {

	// Begin initializes the backend for rendering at the given dimensions.
	// This must be called before any drawing operations.
	// Returns an error if initialization fails.
	Begin(width, height int) error

	// End finalizes the rendering and prepares the output.
	// After End is called, output methods (WriteTo, SaveToFile) can be used.
	// Returns an error if finalization fails.
	End() error

	// Save saves the current graphics state (transform, clip) onto a stack.
	// The state can be restored with Restore.
	Save()

	// Restore restores the graphics state from the stack.
	// If the stack is empty, this is a no-op.
	Restore()

	// Concat multiplies the given matrix into the current transformation
	// matrix. Transform ops in a recording are relative: the backend composes
	// onto the CTM it already has, so a playback context pre-set with a layer
	// offset and device scale renders the recording in the right place.
	Concat(m Matrix)

	// SetClip sets the clipping region to the given path.
	// Only pixels inside the path (according to the fill rule) will be drawn.
	// The clip is intersected with any existing clip.
	SetClip(path *render.Path, rule FillRule)

	// ClearClip removes any clipping region.
	ClearClip()

	// ClipRect intersects the clip region with an axis-aligned rectangle given
	// in user space. It is the cheaper counterpart of SetClip for rects.
	ClipRect(rect Rect)

	// ClipRectOp combines the clip region with an axis-aligned rectangle in user
	// space using op — intersect, difference or replace (C.06). ClipRect is the
	// intersect-only special case.
	ClipRectOp(rect Rect, op render.ClipOp)

	// ClipPathOp combines the clip region with the path using op and the fill
	// rule, the operation-complete counterpart of SetClip.
	ClipPathOp(path *render.Path, rule FillRule, op render.ClipOp)

	// ClipRoundRect intersects the clip region with a rounded rectangle in user
	// space. Playback must take the same call the paint walk made: re-expressing
	// it as a path changes the rasterizer's route (a CPU clip mask instead of
	// the rounded-corner coverage the live canvas uses), which is both slower and
	// a fidelity difference between live paint and replay.
	ClipRoundRect(x, y, w, h, radius float64)

	// FillPath fills the given path with the brush color/pattern.
	// The rule determines how to handle self-intersecting paths. blend is the
	// Porter-Duff mode the recording captured for this draw; backends apply it
	// for this call only.
	FillPath(path *render.Path, brush Brush, rule FillRule, blend render.BlendMode)

	// StrokePath strokes the given path with the brush and stroke style.
	StrokePath(path *render.Path, brush Brush, stroke Stroke, blend render.BlendMode)

	// FillRect is an optimized method for filling axis-aligned rectangles.
	// Backends may implement this more efficiently than FillPath with a rect path.
	FillRect(rect Rect, brush Brush, blend render.BlendMode)

	// StrokeRect strokes an axis-aligned rectangle kept in user space, the
	// stroking counterpart of FillRect.
	StrokeRect(rect Rect, brush Brush, stroke Stroke, blend render.BlendMode)

	// DrawImage draws an image buffer through the recorded options. Backends
	// receive the same render.DrawImageOptions the caller recorded (destination,
	// source sub-rect, interpolation, opacity, blend mode), so replay reaches the
	// rasterizer without losing fields the display list never stored.
	DrawImage(img *render.ImageBuf, opts render.DrawImageOptions)

	// DrawImageNine stretches the edges of img between the centre patch bounds
	// to fill dst, keeping the corners at native size.
	DrawImageNine(img *render.ImageBuf, center image.Rectangle, dst Rect)

	// DrawImageQuad maps img onto an arbitrary quad.
	DrawImageQuad(img *render.ImageBuf, corners [4]render.Point, opts render.QuadDrawOptions)

	// DrawImageRounded draws img clipped to a rounded rectangle.
	DrawImageRounded(img *render.ImageBuf, x, y, radius float64)

	// DrawImageCircular draws img clipped to a circle.
	DrawImageCircular(img *render.ImageBuf, cx, cy, radius float64)

	// DrawAtlas draws a batch of sprites sampled from one image.
	DrawAtlas(img *render.ImageBuf, sprites []render.AtlasSprite, opts render.AtlasDrawOptions)

	// DrawDepthSprites draws a sprite batch carrying per-sprite depth.
	DrawDepthSprites(img *render.ImageBuf, sprites []render.DepthSprite, opts render.DepthDrawOptions)

	// DrawVertices draws an immediate-mode vertex mesh. brush is the fill paint
	// recorded with the mesh — the fallback colour when a mesh carries fewer
	// colours than vertices.
	DrawVertices(positions []render.Point, colors []render.RGBA, mode render.VertexMode, brush Brush)

	// DrawMesh draws an indexed (or triangle-list) coloured mesh. brush is the
	// fill paint recorded with it, the fallback when the mesh carries no per
	// vertex colours.
	DrawMesh(mesh render.Mesh, brush Brush)

	// DrawGlyphs draws a shaped-glyph run at the baseline origin. colored selects
	// the per-glyph colour variant over the single-brush run, which uses brush.
	DrawGlyphs(glyphs []text.ShapedGlyph, face text.Face, x, y float64, colored bool, brush Brush)

	// DrawText draws text at the given position with the specified font face and brush.
	// The position (x, y) is the baseline origin of the text.
	DrawText(s string, x, y float64, face text.Face, brush Brush)

	// SetTextDecoration sets the decoration bitset for text drawn afterwards.
	SetTextDecoration(deco render.TextDecoration)

	// SetTextMode selects the text rendering strategy for text drawn afterwards.
	SetTextMode(mode render.TextMode)

	// SetLCDLayout sets the LCD subpixel order for ClearType text.
	SetLCDLayout(layout render.LCDLayout)

	// SetAntiAlias enables or disables anti-aliasing for the geometry and clips
	// drawn afterwards.
	SetAntiAlias(enabled bool)

	// ApplyBlur attaches a blur post-effect to subsequent draws.
	ApplyBlur(radius float64)

	// ApplyColorMatrix attaches a 4x5 colour matrix post-effect.
	ApplyColorMatrix(matrix [20]float32)

	// ApplyDropShadow attaches a drop-shadow post-effect.
	ApplyDropShadow(offsetX, offsetY, blurRadius float64, color render.RGBA)

	// ApplyGrayscale desaturates subsequent draws.
	ApplyGrayscale()

	// PushLayer opens a layer composited onto the parent with blend and opacity.
	PushLayer(blend render.BlendMode, opacity float64)

	// PushLayerIsolated opens a forced true save-layer.
	PushLayerIsolated(opacity float64)

	// PushBackdropLayer opens a layer seeded from the parent's contents.
	PushBackdropLayer(blend render.BlendMode, opacity float64)

	// PopLayer composites the innermost layer.
	PopLayer()
}
    Backend is the interface that all export backends must implement. Backends
    receive high-level drawing commands and translate them to their output
    format (raster pixels, PDF content streams, SVG elements, etc.).

    A Backend manages its own state stack for Save/Restore operations and
    handles coordinate transformations as needed (e.g., PDF Y-flip).

    Backends are created via the registry using NewBackend(name) and registered
    via Register() in their init() functions.

    # Implementation Contract

    Each backend must:
     1. Register in init() using recording.Register()
     2. Handle all Backend methods (even if no-op for some)
     3. Manage own state stack for Save/Restore
     4. Translate coordinates if needed (e.g., PDF Y-flip)

    # Coordinate contract

    All geometry handed to a Backend — paths, rects, image destinations and
    text positions — is in USER space. The active CTM is whatever the replayed
    ConcatCommand stream composed on top of the matrix the backend already
    had when playback began (Save/Restore nest it). Backends draw through
    that matrix instead of resetting it: recordings carry no baked device
    coordinates, so one recording replays correctly at any device scale and
    under any layer offset.

    # Example Backend Registration

            recording.Register("pdf", func() recording.Backend {
                return NewPDFBackend()
            })
        }

type Brush interface {
	// Has unexported methods.
}
    Brush represents a fill/stroke style for recording commands. This is a
    sealed interface - only types in this package implement it.

    Unlike render.Brush which is designed for immediate-mode rendering with
    ColorAt, recording.Brush stores the brush definition for later playback to
    different backends (raster, PDF, SVG).

func FromRenderBrush(b render.Brush) Brush
    FromRenderBrush converts a render.Brush to a recording.Brush. This extracts
    the brush definition for storage in a recording.

func FromRenderPattern(p render.Pattern, pool *ResourcePool) Brush
    FromRenderPattern converts a render.Pattern into a recorded brush. render's
    own paint treats a solid pattern as an inline colour, an image pattern as
    a data description, and anything else as a live sampler, so the recording
    splits the same three ways. The pool is where the pattern's image gets
    registered, so a retained packet keeps sealing it (see Recording.ImageBufs).

type BrushRef uint32
    BrushRef is a reference to a brush in the resource pool. The zero value is a
    valid reference to the first brush (if any).

func (r BrushRef) IsValid() bool
    IsValid returns true if the reference points to a valid brush.

type CanvasBackend struct {
	// Has unexported fields.
}
    CanvasBackend replays a Recording onto a render.Canvas.

    This is the primary playback path — the counterpart of SkPicture::playback
    (SkCanvas*): the recording is a display list in user space, and the target
    canvas supplies the coordinate system it lands in. Playback composes onto
    the canvas's existing CTM and clip instead of replacing them, so a picture
    recorded on the UI thread in layer-local logical pixels rasterizes correctly
    under the layer offset and the device scale that the raster thread already
    set up. Begin pushes the canvas state and End pops it (plus restores the
    brushes, which Context.Pop does not track), so a recording cannot leak into
    whatever the canvas paints next.

    Taking the interface rather than the live context is what makes recordings
    composable: replaying onto a *Recorder folds the commands into the
    surrounding recording, so one display list can be reused inside another and
    the same call works while recording and while rasterizing.

    The raster image backend is a thin wrapper around this type; both share one
    interpretation of the command stream.

func NewCanvasBackend(dc render.Canvas) *CanvasBackend
    NewCanvasBackend returns a backend that draws into dc. The canvas keeps its
    own size, scale and clip; the recording is positioned by composing onto them
    at playback.

type Command interface {
	// Type returns the CommandType for this command.

    Command is the interface implemented by all command types. Commands

    to a specific drawing operation.

type ConcatCommand struct {
	// Matrix is the relative transformation to concatenate.
	Matrix Matrix
}
    ConcatCommand concatenates a matrix onto the playback CTM.

    Transform ops are relative, not absolute: the matrix maps the CTM the
    recorder had before the call to the CTM it had after. Playback therefore
    composes onto whatever CTM the target context already carries (the layer
    offset and device scale at raster time) instead of clobbering it — the same
    model Skia's display lists use, and what makes one recording replayable at
    any scale and offset.

    Type implements Command.

type Recorder struct {
	// Has unexported fields.
}
    Recorder captures drawing operations as commands. It mirrors the
    render.Context drawing API but generates commands instead of rasterizing
    pixels. Use FinishRecording to obtain an immutable Recording that can be
    replayed to different backends.

    # Coordinate space

    Geometry is stored in user space: the recorded transforms travel in the
    command stream as relative concats (ConcatCommand) and each backend applies
    them onto its own CTM. This matches render.Context, whose path verbs are
    baked by the user matrix and whose device scale is folded in only at the
    rasterization boundary (totalMatrix). A recording therefore replays crisp at
    any device scale and survives layer offsets without being re-recorded.

    Example:

        rec := recording.NewRecorder(800, 600)
        rec.SetRGB(1, 0, 0)
        rec.DrawCircle(100, 100, 50)
        rec.Fill()
        recording := rec.FinishRecording()

    The Recorder is not safe for concurrent use.

    miter joins, non-zero fill rule, and identity transform.

type Recording struct {
	// Has unexported fields.
}
    Recording is an immutable container for recorded drawing commands. It can be
    replayed to any Backend implementation.

func (r *Recording) Bounds() image.Rectangle
    Bounds returns the recording's content footprint in the recording's own
    coordinate space — that is, where the geometry lands when playback starts
    from the identity CTM. It is the layer-local, scale-agnostic space the
    recorder was drawn in: the raster thread's layer offset and device scale
    compose onto it at playback, so a consumer sizes and damages a surface by
    scaling this rect, never by re-measuring the commands.

    The rect is a superset by construction: clips are not intersected,
    zero-alpha paint still counts as geometry, and a recording carrying a blur
    or drop shadow reports the whole canvas, because those filters act on the
    surface rather than on the command that follows. Empty means nothing was
    recorded; a nil recording is empty.

func (r *Recording) Commands() []Command
    Commands returns the recorded commands.

func (r *Recording) HasVisiblePaint() bool
    HasVisiblePaint reports whether replaying this recording can put a pixel on
    the surface. Command count is not the question: a recording of empty paths,
    zero-alpha fills and brush-less geometry is legal but invisible, and
    feeding one to a texture allocator would spend a surface to show nothing.
    A nil recording paints nothing.

func (r *Recording) Height() int
    Height returns the height of the recording canvas.

func (r *Recording) ImageBufs() []*render.ImageBuf
    ImageBufs returns the image buffers the recording draws from, in pool order.
    A retained packet must hold these for as long as it may replay them:
    the recording stores buffers by pointer (no pixel copy), so disposing one
    while a recording still references it leaves a disposed image at playback.
    The result is read-only. A nil recording draws from no buffers.

func (r *Recording) NeedsCPUPassScratch() bool
    NeedsCPUPassScratch reports whether a replay can put pixels on the surface
    through the CPU: it draws from an image buffer, and an image path without
    a GPU resource samples on the CPU. A rasterizer recording the replay into a
    GPU texture must swap in a CPU scratch pixmap for the pass or those pixels
    miss the texture; a recording with no image commands is provably GPU-only
    and can skip the swap at zero behavior change. A nil recording needs no
    scratch.

func (r *Recording) PaintOpCount() int
    PaintOpCount returns the display-list length: the number of commands a
    replay issues work for. State, clip and layer commands are not counted,
    so this is what a per-frame op budget should charge a recording for.
    A nil recording carries no work.

func (r *Recording) Playback(backend Backend) error
    Playback replays the recording to the given backend.

func (r *Recording) Resources() *ResourcePool
    Resources returns the resource pool.

func (r *Recording) Width() int
    Width returns the width of the recording canvas.

type ResourcePool struct {
	// Has unexported fields.
}
    ResourcePool stores resources referenced by recording commands. Resources
    are stored in slices indexed by their reference types. Each Add operation
    clones mutable resources to ensure immutability.

    Images are pooled as *render.ImageBuf — the very type render.Context draws
    from. Holding image.Image instead would force a FromStdImage copy on every
    playback (per-pixel for exotic types), which is both slow and loses the
    buffer's GPU texture identity (genID), so a recording would re-upload a new
    texture each frame.

    ResourcePool is not safe for concurrent use. If concurrent access is needed,
    external synchronization must be provided.

func NewResourcePool() *ResourcePool
    NewResourcePool creates an empty resource pool with pre-allocated capacity.

func (p *ResourcePool) AddBrush(brush Brush) BrushRef
    AddBrush adds a brush to the pool and returns its reference. Brushes are
    stored directly as they are typically immutable value types.

func (p *ResourcePool) AddFont(face text.Face) FontRef
    AddFont adds a font face to the pool and returns its reference. Font faces
    are stored directly as they are already immutable and safe to share.

func (p *ResourcePool) AddImageBuf(img *render.ImageBuf) ImageRef
    AddImageBuf pools a render buffer and returns its reference. The buffer is
    stored by pointer: recordings do not copy pixels, and playback draws the
    same buffer the caller recorded (ImageBuf's own copy-on-write/ownership
    rules apply — callers must not Dispose it while a recording still references
    it).

func (p *ResourcePool) AddPath(path *render.Path) PathRef
    AddPath adds a path to the pool and returns its reference. The path is
    cloned to ensure immutability of the recording.

func (p *ResourcePool) BrushCount() int
    BrushCount returns the number of brushes in the pool.

func (p *ResourcePool) Clear()
    Clear removes all resources from the pool. This does not release the
    underlying memory; use NewResourcePool for that.

func (p *ResourcePool) Clone() *ResourcePool
    Clone creates a deep copy of the resource pool. Paths are cloned; other
    resources are copied by reference (they are immutable).

func (p *ResourcePool) FontCount() int
    FontCount returns the number of font faces in the pool.

func (p *ResourcePool) GetBrush(ref BrushRef) Brush
    GetBrush returns the brush for the given reference. Returns nil if the
    reference is invalid.

func (p *ResourcePool) GetFont(ref FontRef) text.Face
    GetFont returns the font face for the given reference. Returns nil if the
    reference is invalid.

func (p *ResourcePool) GetImage(ref ImageRef) *render.ImageBuf
    GetImage returns the image for the given reference. Returns nil if the
    reference is invalid.

func (p *ResourcePool) GetPath(ref PathRef) *render.Path
    GetPath returns the path for the given reference. Returns nil if the
    reference is invalid.

func (p *ResourcePool) ImageCount() int
    ImageCount returns the number of images in the pool.

func (p *ResourcePool) Images() []*render.ImageBuf
    Images returns the pooled image buffers in insertion order. The result is
    read-only: a caller that retains the buffers (a packet pinning them against
    disposal) must not append to or reorder it.

func (p *ResourcePool) PathCount() int
    PathCount returns the number of paths in the pool.

type SweepGradientBrush struct {
	Center     render.Point   // Center of the sweep
	StartAngle float64        // Start angle in radians
	EndAngle   float64        // End angle in radians
	Stops      []GradientStop // Color stops defining the gradient
	Extend     ExtendMode     // How gradient extends beyond bounds
}
    SweepGradientBrush is an angular (conic) gradient brush. Colors sweep from
    StartAngle to EndAngle around Center.

func NewSweepGradientBrush(cx, cy, startAngle float64) *SweepGradientBrush
    NewSweepGradientBrush creates a new sweep (conic) gradient brush. The
    gradient sweeps a full 360 degrees by default.

func (g *SweepGradientBrush) AddColorStop(offset float64, color render.RGBA) *SweepGradientBrush
    AddColorStop adds a color stop at the specified offset. Offset should be in
    the range [0, 1]. Returns the gradient for method chaining.

func (g *SweepGradientBrush) SetEndAngle(endAngle float64) *SweepGradientBrush
    SetEndAngle sets the end angle of the sweep. Returns the gradient for method
    chaining.

func (g *SweepGradientBrush) SetExtend(mode ExtendMode) *SweepGradientBrush
    SetExtend sets the extend mode for the gradient. Returns the gradient for
    method chaining.

type WriterBackend interface {
	Backend

	// WriteTo writes the rendered content to the given writer.
	// This should only be called after End().
	// Returns the number of bytes written and any error.
	WriteTo(w io.Writer) (int64, error)
}
    WriterBackend extends Backend with the ability to write output to an
    io.Writer. This is useful for streaming output or writing to network
    connections.
