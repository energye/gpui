Example: Scene rendering with GPU acceleration

Demonstrates the GPU auto-select path in scene.Renderer. When `import _
"gg/gpu"` registers the GPU accelerator, scene.Renderer automatically routes
through GPUSceneRenderer instead of the CPU tile-parallel path.

The same scene code works identically with or without GPU — remove the gpu
import to fall back to CPU rendering.

Output: tmp/render_scene_gpu.png (512x512)
