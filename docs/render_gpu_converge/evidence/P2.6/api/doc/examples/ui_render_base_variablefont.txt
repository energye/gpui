Command ui_render_base_variablefont is the B-group direct
real window for variable-font loading and variation selection:
Context.LoadFontFaceWithVariations, Context.FontVariationAxes,
text.FontSource.Face + WithVariations, VariationAxes and NamedInstances.

    export LD_LIBRARY_PATH=$PWD/lib WGPU_NATIVE_PATH=$PWD/lib/libwgpu_native.so
    RUN_SECONDS=5 go run ./examples/ui_render_base_variablefont -auto-only
    go run ./examples/ui_render_base_variablefont   # manual: lives until window close
    go run ./examples/ui_render_base_variablefont -manual-seconds 15

Evidence: logical contract probes on the public text API, point + region pixel
probes on the GPU snapshot, and a bitwise golden over header + legend + the four
cards. The visual sample is SourceSans3VF-Upright.otf, committed under testdata;
the ink oracle comes from the pixels, not from Face.Advance.
