filters (RENDER_FEATURE_COVERAGE §1 #40 / §3.1): ApplyInvert, ApplyBlurXY,

    go run ./examples/ui_render_base_filterops   # manual: lives until window close
    go run ./examples/ui_render_base_filterops -manual-seconds 15

probes over the GPU snapshot, a bitwise golden over header + legend + the four
cards, a live screen grab compared with the snapshot over the same rects,
and per-card GPU-route assertions (filter gpu_ops > 0, cpu_fallback_ops == 0).
