Window: 1200x800. R1 table floor is 5s (U16); close evidence uses 30s because
the two U21 snapshot readbacks would otherwise exceed the hitch budget.
GPU window required.

R1 thesis: changing one child's layout size must dirty only its relayout
boundary subtree — never the window root, the shell panels, or sibling boards.
The target frame is a real engine relayout boundary; four timed height changes
move its Align child (the amber marker), while the sibling chip, dense board,
stripes, and persistent HOT animation stay put.
