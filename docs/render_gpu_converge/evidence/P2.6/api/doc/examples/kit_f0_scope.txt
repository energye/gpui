Command kit_f0_scope is the F0-1 real-window: theme plus scope.

RUN_SECONDS=5 go run ./examples/kit_f0_scope

Window: 1200x800 baseline, user-resizable. The run performs one scripted resize
excursion and restores the baseline, so layout follows real EventResize traffic
before any gate is read. Correctness window (RUN_SECONDS>=5): slope_gate=off,
fps gate on (continuous tick), pixel probes F0+F6, golden zero-tolerance.
