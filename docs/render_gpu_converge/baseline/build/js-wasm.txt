# js/wasm 目标：登记为不支持（P1.1b，2026-10-28）

结论：js/wasm 不在基线必绿目标内。根因在外部 FFI 库，不在本项目构建标签。

- 复跑命令与原始输出：`evidence/P1.1b/js-wasm.txt`
- 根因一句话：`../purego` 的构建标签只覆盖 `darwin || freebsd || linux || netbsd || windows`，
  wasm 没有任何实现；`gpu/render/ui/engine/video` 栈 302 个包都传递依赖它。
- 典型错误：`../purego/struct_other.go:21:46: undefined: syscallArgs`
- 将来若要支持 wasm：需为浏览器 WebGPU 新写 `syscall/js` 后端（等同新增后端能力，单独立项）。
