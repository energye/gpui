package theme // import "github.com/energye/gpui/ui/theme"

Package theme provides a minimal token map and provider stack (P5e).

Not Ant Design's full token table and not a CSS selector engine. Widgets read
Tokens via Provider.Current() (global default + optional overrides).

VARIABLES

var Default = NewProvider(DefaultTokens())
    Default is the process-wide provider (lazy DefaultTokens).


TYPES

type Color struct {
	R, G, B, A float64
}
    Color is an sRGB color in 0..1 (matches painting fill convention).

func Hex(s string) Color
    Hex parses #rgb / #rrggbb into Color (alpha 1). Invalid input returns zero.

func RGBA(r, g, b float64, a float64) Color
    RGBA builds a Color from 0..255 channels and 0..1 alpha.

type Provider struct {
	// Has unexported fields.
}
    Provider holds the active token set with an optional override stack.

    Command-style API: Push/Pop for local scopes (e.g. dialog chrome).
    Thread-safe for concurrent read; Push/Pop intended on UI thread.

func NewProvider(base Tokens) *Provider
    NewProvider creates a provider with the given base tokens. If base is
    zero-ish (FontSize==0), DefaultTokens is used.

func (p *Provider) Base() Tokens
    Base returns the root tokens (ignoring overrides).

func (p *Provider) Current() Tokens
    Current returns the top-of-stack tokens, or base if the stack is empty.

func (p *Provider) Depth() int
    Depth returns override stack depth.

func (p *Provider) Pop()
    Pop removes the top override. No-op if empty.

func (p *Provider) Push(t Tokens)
    Push pushes an override (typically a modified copy of Current()).

func (p *Provider) SetBase(t Tokens)
    SetBase replaces the root tokens (does not clear the override stack).

func (p *Provider) With(t Tokens, fn func())
    With runs fn under tokens t and restores the previous stack depth.

    Tokens is the global seed token set, aligned to antd v6.5.1 default theme.

    Old short names (Primary/Surface/...) stay for compat and now map to the Ant
    values below. New Seed_* / Alias_* fields carry the full global seed so L2
    assertions have numbers to check. Component-specific tokens land with each
    ui/kit/<name>/ package, not here.

func DefaultTokens() Tokens
    DefaultTokens returns the Ant Design v6.5.1 default (light) seed.

    Source: components/theme/themes/seed.ts + shared derivatives
    (font/size/radius/control) + util/alias.ts (padding/margin/shadow).

func (t Tokens) Space(n float64) float64
    Space returns n × Spacing.
