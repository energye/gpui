func ApplyBlur(pc *PaintContext, radius float64)
    ApplyBlur applies a uniform Gaussian blur to the current surface (FF-BLUR /
    FP-IMAGE-FILTER). radius <= 0 is a no-op.

func ApplyColorMatrix(pc *PaintContext, matrix [20]float32)
    ApplyColorMatrix applies a 4×5 row-major color matrix to the current surface
    (FF-COLOR-MATRIX). Matrix layout matches render.ApplyColorMatrix.

func ApplyDropShadow(pc *PaintContext, offsetX, offsetY, blurRadius, r, g, b, a float64)
    ApplyDropShadow composites a drop shadow under the current surface contents
    (FC-DRAW-SHADOW / FF filter path). offset is in logical px (Y-down);
    blurRadius is the shadow soft radius; color is 0..1 RGBA.

    Full-surface filter — not a path-bound Material elevation API.
    No explicit GPU flush here: render's own filter paths already drain
    pending batches before reading back (filter_ops_cpu.go / m4_quadimage.go /
    filter_ops_gpu.go).

func ApplyGrayscale(pc *PaintContext)
    ApplyGrayscale converts the current surface to grayscale via the shipped
    render color-matrix path (FF-COLOR-MATRIX / FP-COLOR-FILTER).

func BuildFramePacket(root RenderObject, frameID uint64, dpr, w, h float64) *scene.FramePacket
    BuildFramePacket layouts are assumed already flushed; builds
    a packet for raster. Overlay band is an empty F13 reserve; use
    overlay.State.AttachToPacket to fill it.

    D3 inline mode: this is the synchronous inline path for unit tests (no
    raster Loop involved). Windows go through the async embedder+raster Loop;
    the packet shape is identical on both paths.

func BuildFramePacketOverlay(root RenderObject, frameID uint64, dpr, w, h float64, attach func(pkt *scene.FramePacket)) *scene.FramePacket
    BuildFramePacketOverlay builds the main packet then attaches ov to
    pkt.Overlay. ov may be nil (empty band). Main DirtyLayerIDs are preserved
    and overlay dirties appended. The attach callback is the EndFrame tail:
    it runs before the seal so the handed-off packet already carries both bands.

func BuildFramePacketWithSaveLayer(root RenderObject, frameID uint64, dpr, w, h float64, stats *SaveLayerStats, budget *SaveLayerBudget) *scene.FramePacket
    BuildFramePacketWithSaveLayer builds the packet like BuildFramePacket while
    wiring the embedder-owned per-frame SaveLayer budget and outcome stats
    into raster-time OnPaint callbacks. Retained mode defers RenderBox.OnPaint
    to texture-record time; without this wiring a configured budget
    (PipelineOptions SaveLayerMaxOps/MaxArea) never sees those requests.
    stats/budget may be nil (= BuildFramePacket behavior).

func DrawAtlas(pc *PaintContext, img *render.ImageBuf, sprites []AtlasSprite)
    DrawAtlas draws multiple sprites from one atlas image (FImg-ATLAS). Each
    sprite's DstX/DstY are origin-relative local coordinates (shifted by Abs).
    Src* stay in image pixel space. Empty sprites slice is a no-op.

func DrawGPUTexture(pc *PaintContext, view render.TextureView, x, y float64, width, height int) bool
    DrawGPUTexture paints a live GPU texture view into the current walk
    (render.Context.DrawGPUTexture subset). x,y are in the walk's user space
    (pc.Abs for origin-relative paint), width/height in the same space.

    A recording walk stores the command instead of refusing it; only a target
    with no texture capability is refused, counted in LiveOnlySkips.

func DrawImageBuf(pc *PaintContext, img *render.ImageBuf, x, y, dstW, dstH float64)
    DrawImageBuf draws img at local (x,y). If dstW and dstH are both >0 the
    image is scaled into that destination (DrawImageEx); otherwise it is drawn
    1:1 (DrawImage). Skips disposed or nil buffers (FImg-DRAW / FC-DRAW-IMAGE).

func DrawImageCircular(pc *PaintContext, img *render.ImageBuf, cx, cy, radius float64)
    DrawImageCircular draws img centered at local (cx,cy), clipped to a circle
    of the given radius and scaled to the circle diameter (FImg-CIRCLE).
    radius<=0 is a no-op. Origin-aware.

func DrawImageNine(pc *PaintContext, img *render.ImageBuf, center image.Rectangle, x, y, dstW, dstH float64)
    DrawImageNine draws a nine-patch (lattice) image into a destination rect
    (FImg-NINE / FC-DRAW-IMAGE-NINE). center is the stretchable center rectangle
    in source image pixel coordinates. Corners stay unscaled; edges stretch on
    one axis; center stretches on both. Origin-aware.

func DrawImageRect(pc *PaintContext, img *render.ImageBuf, src image.Rectangle, x, y, dstW, dstH float64)
    DrawImageRect draws a source rectangle of img into a destination rect in
    local coordinates (FImg-RECT / FC-DRAW-IMAGE-RECT). src is in image pixel
    space; if empty, the full image is used. dstW/dstH must be >0.

func DrawImageRounded(pc *PaintContext, img *render.ImageBuf, x, y, radius float64)
    DrawImageRounded draws img at its natural size with a uniform rounded-rect
    clip (FImg-ROUND / FC-DRAW-IMAGE path). radius<=0 draws without rounding
    (hard rect). Origin-aware like DrawImageBuf.

func DrawPoints(pc *PaintContext, pts []float64, radius, r, g, b, a float64)

func SnapCoord(v, scale float64) float64
    SnapCoord rounds a logical coordinate onto the device pixel grid (R19 1px
    alignment). Skia/Flutter-style: logical v maps to physical v*scale; rounding
    to the nearest physical pixel and mapping back gives a coordinate that lands
    exactly on a device pixel boundary, so hairlines stay crisp on HiDPI.

        scale <= 0 falls back to 1 (identity DPR).

func SnapLine(v, scale float64) float64
    SnapLine returns the device-aligned centerline (x for vertical lines, y for
    horizontal lines) of a 1px stroke so the stroke covers exactly one physical
    pixel column/row (crisp, not blurred between two pixels). Flutter/Skia
    hairline practice: a stroke of width 1/scale is centered on the middle of
    a physical pixel, i.e. (floor(v*scale)+0.5)/scale. Keep SnapCoord (pixel
    boundaries) for fills; this half-pixel center is only for line strokes.

func SnapPixel(x, scale float64) float64
    SnapPixel 对齐到物理像素（HiDPI 1.25/2.0 1px 采样，F0–F9）.

func SnapRect(x, y, w, h, scale float64) (sx, sy, sw, sh float64)
    SnapRect snaps a rectangle's origin and size onto the device grid, keeping
    the right/bottom edges on grid too (used for 1px borders that must not
    flicker between widths at fractional DPR).

    bubbles up through ancestors and STOPS at the nearest RepaintBoundary — the

    MarkNeedsPaint is idempotent: already-dirty nodes skip redundant marking.

type BoundaryCache struct {
	// Has unexported fields.
}
    BoundaryCache holds display-list-backed caches for RepaintBoundary nodes.
    Clean boundaries replay the stored Recording (skip re-record); dirty ones
    re-paint and re-record. Works under FullPaint so skip is observable without
    Retained Present.

    Nested model (Flutter layers, recording MVP):
      - Each RepaintBoundary owns a Recording of **own content only**.
      - Nested IsRepaintBoundary children are NEVER baked into the parent
        Recording; after a container tryReplay the caller still walks nested RB
        children so each child can tryReplay/rerecord independently.
      - Therefore only-inner-dirty never forces an outer rerecord, and a clean
        outer replay cannot show stale child colors.

    Cacheability (correctness-first): a boundary whose own content contains
    RO types the recorder cannot faithfully capture (e.g. Viewport) is marked
    not-cacheable — tryReplay/store are no-ops for it, so the subtree always
    live-paints and stale-frame content loss is impossible.

func NewBoundaryCache() *BoundaryCache
    NewBoundaryCache creates an empty cache.

func (c *BoundaryCache) BeginFrame()
    BeginFrame resets per-frame skip/rerecord/miss counters (call once per
    present paint) and advances the eviction generation, periodically sweeping
    untouched entries.

func (c *BoundaryCache) Clear()
    Clear drops all display-list entries.

func (c *BoundaryCache) HasValid(n RenderObject) bool
    HasValid reports whether n currently has a reusable display-list entry.

func (c *BoundaryCache) Invalidate(n RenderObject)
    Invalidate drops the recording for this node (size/content change).

func (c *BoundaryCache) Len() int
    Len returns the number of cached boundary entries.

func (c *BoundaryCache) MaxEntries() int
    MaxEntries returns the explicit budget cap (0 = unlimited).

func (c *BoundaryCache) SetMaxEntries(n int)
    SetMaxEntries sets the explicit budget cap. 0 = unlimited (default;
    generational sweep still bounds long-run growth). A cap below the current
    entry count takes effect on the next Store: the oldest-lastSeen entries are
    dropped first until under budget. Correctness never depends on the cache —
    an evicted boundary simply re-records.

    so Stats() is the only sanctioned cross-thread access.

    Paint implements RenderObject.

    Flutter PaintingContext paintChild walk (FPC-COMPOSITE-ONLY, FRO-REPAINT-B):
     1. Skip node entirely if neither it nor any descendant needs paint.
     2. If this node NeedsPaint: draw self and recurse into ALL children

    itself is dirty, so paint_count/visits stay explainable.

type RenderPictureBox struct {
	Base
	Width, Height float64
	// Record builds the box's own display list at absolute origin (ox,oy) on
	// any render.Canvas — the live context on a FullPaint frame, the parent's
	// recorder on a retained frame. Nil Record paints nothing and is never
	// cacheable.
	Record func(dc render.Canvas, ox, oy float64)
}
    RenderPictureBox is a leaf box whose own content is a retained display list
    built by Record (Flutter RepaintBoundary with a full display list).

    Unlike RenderColorBox/RenderText/RenderImage (own content reconstructed from
    fields), a picture box records arbitrary vector content: circles, ovals,
    arcs, round rects, lines, gradients, paths, text and images. Live paint and
    cache record run the SAME Record closure, so replay can never diverge from
    live paint by construction.

    Cache contract (correctness-first): Record must be a pure function of
    the box state. The cache holds no content fingerprint for this type
    (contentKeyOf returns 0) and relies on NeedsPaint for invalidation — call
    MarkNeedsPaint whenever the produced commands would change, otherwise
    clean frames replay a stale display list. Static content never changes,
    so it skips forever after the first record. Use as a RepaintBoundary;
    a non-boundary picture box inside an AbsoluteBox disables that parent's
    caching (absoluteContentCacheable rejects it) instead of risking a stale
    bake — same discipline as Viewport (boundaryCacheable).

    NewRenderPictureBox creates a picture box; record may be nil (paints nothing
    until SetRecord installs one).

func (b *RenderPictureBox) HitTest(p Point) RenderObject
    HitTest implements RenderObject.

func (b *RenderPictureBox) Layout(c Constraints) Size
    Layout implements RenderObject.

func (b *RenderPictureBox) Paint(pc *PaintContext)
    Paint implements RenderObject.

    Clean + valid entry replays from cache (boundary_skip); dirty or missing
    entry builds via Record, replays the same commands, and stores them.
    Single build — live paint and cache record can never diverge.

    Playback targets any Canvas: a live *render.Context rasters the commands
    immediately, a recording.Recorder folds them into the enclosing display list

func (b *RenderPictureBox) SetRecord(record func(dc render.Canvas, ox, oy float64))
    SetRecord installs a new record closure and dirties paint (the cache holds
    no fingerprint for this type, so any Record change must re-record).

    # Nested scroll competition (P5b)

    Default rules (Flutter-like minimum set):

     1. Deepest scrollable handles the gesture first (hit path / Parent chain).
     2. Child not at edge: only the child ScrollOffset changes; parent stays
        put.
     3. Child at edge and drag continues in the overscroll direction: residual
        delta is transferred to Parent (no double-apply of the absorbed part).
     4. Wheel: deepest consumes first; residual bubbles to Parent when
        BubbleWheel is true (default).

    Arena note: when multiple Scrollables join a GestureArena, only one pan
    wins. Nested handoff does **not** re-open the arena mid-gesture; it uses
    the Parent chain residual after the winner applies ScrollBy. Wire Parent
    for nesting; JoinPointer path should list deepest first for fair arena entry
    order.

    Non-goals: multi-axis simultaneous competition, overscroll glow, platform
    pixel-perfect parity.

    P5a: drag uses gestures.PanGestureRecognizer. Wheel bypasses the arena.

func (v *VirtualTextLines) TotalHeight() float64
    TotalHeight返回内容总高.定行高 O(1);变行高为缓存的运行总和 O(1). 变高下含估算成分(I5),精确总高须先
    MeasureWindow.

func (v *VirtualTextLines) Window() (first, lastExclusive int)
    Window返回当前待物化区间 [first,lastExclusive).
