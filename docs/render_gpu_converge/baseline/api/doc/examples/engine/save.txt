Command game_save is the 16.2 quality-tier independent window.

Three cards side by side, one per frozen tier (high 1000 particles plus 8 lights
plus scale 1.00, medium 500 plus 4 plus 0.75, low 200 plus 2 plus 0.50). The
live scene highlights one card at a time and switches the real engine/quality
Quality handle every 2s; the switch only replaces the level, the scene never
reloads, nothing flashes.

Modes:

    go run ./examples/engine/save --case=q123 -auto-only
      headless probes + ~8s window (JSON on stdout, exit 1 on fail).
    go run ./examples/engine/save --case=q123 -manual-seconds 30
      manual for 30s (events logged, title shows the count), then summary.
    go run ./examples/engine/save --case=q123
      probes, then resident until close (RUN_SECONDS sets a timed run).

Window: 1200x800, title game_quality. First run writes the golden baseline into
testdata/; later runs compare it with zero tolerance.
