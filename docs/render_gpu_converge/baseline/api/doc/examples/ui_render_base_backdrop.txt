Command ui_render_base_backdrop is the A-group real window for the backdrop
layer family: PushBackdropLayer (+ ApplyBlur, PopLayer) (RENDER_FEATURE_COVERAGE
§1 #16 / §3.1 item 7).

    export LD_LIBRARY_PATH=$PWD/lib WGPU_NATIVE_PATH=$PWD/lib/libwgpu_native.so
    RUN_SECONDS=5 go run ./examples/ui_render_base_backdrop -auto-only
    GPUI_MSAA=4 RUN_SECONDS=5 go run ./examples/ui_render_base_backdrop -auto-only
    go run ./examples/ui_render_base_backdrop   # manual: lives until window close
    go run ./examples/ui_render_base_backdrop -manual-seconds 15  # manual, auto-close

Evidence: 14 logical contract probes (value-level on an offscreen CPU context),
21 pixel probes on the GPU snapshot (oracle = palette constants + snapshot-dim
math), a bitwise golden over header + legend + the four cards, a GPU-route
assertion (gpu_ops > 0, cpu_fallback_ops == 0), and a live screen grab compared
with the snapshot over the same rects. GPUI_MSAA=4 keeps the base surface at
4x while backdrop layers use their own 1x target and selects the 4x golden
(testdata/showcase_backdrop_msaa4*.png).

The screen check is not optional here: while closing this window the presented
path rendered black (the layer RT's first pass cleared the uploaded backdrop
seed) while the synthetic Close repaint stayed correct. Snapshot green alone
would have been a false green; see README §4.
