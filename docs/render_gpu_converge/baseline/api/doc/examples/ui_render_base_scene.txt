Command ui_render_base_scene is the B-group direct real window for render/scene:
SceneBuilder, Scene/Encoding, the GPU scene renderer, the CPU tile renderer,
LayerCache and damage-tracked incremental rendering.

    export LD_LIBRARY_PATH=$PWD/lib WGPU_NATIVE_PATH=$PWD/lib/libwgpu_native.so
    RUN_SECONDS=5 go run ./examples/ui_render_base_scene -auto-only
    go run ./examples/ui_render_base_scene   # manual: lives until window close
    go run ./examples/ui_render_base_scene -manual-seconds 15

Evidence: logical contract probes (encoding round-trip, brush-sensitive hash,
cache entries, layer alpha/blend, round-rect clipping, damage region and
incremental == full), point/ink probes on the GPU snapshot, an A/B parity check
between the same scene rendered by the GPU path (card A) and the CPU tile path
(card B), and a bitwise golden over header + legend + four cards.
