Command ui_wr_c0_smoke is the W0 C0 composite real-window: R0+R12+R16 集成.

    export LD_LIBRARY_PATH=$PWD/lib WGPU_NATIVE_PATH=$PWD/lib/libwgpu_native.so
    RUN_SECONDS=5 go run ./examples/ui_wr_c0_smoke -auto-only -gate-stage pre
    RUN_SECONDS=5 go run ./examples/ui_wr_c0_smoke -auto-only -gate-stage post
    go run ./examples/ui_wr_c0_smoke                 # manual: animate until close
    go run ./examples/ui_wr_c0_smoke -manual-seconds 15

Window: 1200x800. RUN_SECONDS>=5 (U16). GPU window required. C0 is an
integration window only; it does NOT replace the individual R0/R12/R16 windows
(§3 combination table).

Evidence (U21): the gate has two deterministic stages so both the boot state and
the recovery state are pixel-asserted:
  - pre: first-frame content is frozen (steady phase, no recovery); static grid
    + text + schema labels + first-frame banner are all placed before Open(),
    so the final snapshot is content-equivalent to the first frame.
  - post: recovery is triggered at a fixed tick and the recovery state is
    held to the end; the snapshot proves full-tree repaint survived while the
    static/schema content stayed alive.

Each stage writes its own GPU-readback PNG, pixel probes, and bitwise golden
(header + legend + body; the live HUD band is excluded). Manual mode keeps the
Steady→Spike→Recover animation, scrolls schema keys, and shows the one-second
recovery banner.
