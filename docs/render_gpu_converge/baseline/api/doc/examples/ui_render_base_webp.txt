Command ui_render_base_webp is the A-group real window for WebP loading and
decoding (RENDER_FEATURE_COVERAGE §1 #22 / §3.1 item 13).

    export LD_LIBRARY_PATH=$PWD/lib WGPU_NATIVE_PATH=$PWD/lib/libwgpu_native.so
    RUN_SECONDS=5 go run ./examples/ui_render_base_webp -auto-only
    go run ./examples/ui_render_base_webp   # manual: lives until window close
    go run ./examples/ui_render_base_webp -manual-seconds 15  # manual, auto-close

Evidence: 19 value-level contract probes (CPU child), point + region pixel
probes on the GPU snapshot, a bitwise golden over header + legend + the four
cards, a GPU-route assertion (no CPU fallbacks), and a live screen grab compared
with the snapshot over the same rects.

Scope: LoadWebP decodes VP8/VP8L through golang.org/x/image/webp. The lossless
card is compared bit-exactly with a PNG reference (including alpha); the lossy
card checks the VP8 path and a bounded decoder-difference mean. The `.bin` card
proves LoadImage content sniffing; the error card proves missing/non-WebP/empty
inputs return errors without a placeholder or panic.
