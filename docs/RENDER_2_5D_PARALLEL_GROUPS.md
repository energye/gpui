# 2.5D 功能点并行分组（按优先级与依赖顺序，2026-09-17）

来源：`docs/RENDER_2_5D_GAP_PLAN.md`（§0 冻结目标、开发依赖顺序 W0–W24、各阶段能力行）。
口径：S00–S112 共 113 号，S80、S101 作废，实做 111 项，每项只出现一次。
规矩（照抄总账）：上一组没绿下一组别开；同组内可并行；标串行的必须一个做完再做下一个。
状态只有四种：未开工、进行中、已完成、冻结；“已完成·V1口径”是已完成的标注写法（V1口径完成、§5待回炉）。
组状态由成员推导：全员已完成·V1口径→已完成·V1口径；全员未开工→未开工；混杂→进行中（以最低成员为准）。
