# 像素级断言规范（真窗视觉正确性 · 硬）

> **状态真源：本规范已并入 `docs/ENGINE_UI_WIDGET_RENDER.md` §2.7（U21）。本文件为独立完整版，便于查阅与引用；两处内容一致，修订须同步。**

## 0. 定位与适用范围

- **适用对象：所有 `ui_wr_*` 真窗（R 单能力窗与 C 组合窗）中的一切可见图形**——哪个 R 有对应图形，就按本规范对相应形态做断言。C8 只是暴露问题的地方，不是规范的边界。
- **目标：支撑 GUI 工业级组件与任意图形绘制。** 逻辑指标（hitTest 探针、rerecord/skip、fps）证明「行为对」；本规范约束「**画面对**」。两者缺一不可——C8 曾出现「探针全 ok 但画面内容消失」的假绿。
- **标准对齐（Flutter/Skia 源码核实，非凭印象）：**
  - **Golden 逐像素基线对比**（flutter_test `goldens.dart` / `_goldens_io.dart` `compareLists`）：渲染结果与基线 PNG 逐像素 RGBA 对比，默认**零容差**（任一通道差即 FAIL）、尺寸不匹配直接 FAIL；需要容忍时必须**显式声明** `precisionTolerance` 并写明依据。失败时产出 maskedDiff/isolatedDiff 差异图定位差异区。
  - **captureImage 取 RepaintBoundary image**（flutter_test `_matchers_io.dart`）：像素验证的取样对象是最近 RepaintBoundary 渲染出的 image，不走窗口背存（X11 背存滞后于合成内容——本项目 `SnapshotPath` GPU readback 注释同一结论）。
  - **hitTestable finder**（flutter_test `finders.dart:1464`）：「画出来的 ≡ 点得到的」是 Flutter 官方测试原语——元素局部坐标取点转全局后走 `hitTestInView` 断言命中路径。像素断言必须与之配对，防「画错位置但颜色对」。
  - **确定性帧推进**（flutter_test `widget_tester.dart` `pumpFrames` + FakeAsync）：动画在固定时间步下逐帧推进，第 N 帧 state 确定 → 采样可复现。禁止真实时间里盲采。

## 1. 总原则（硬）

1. **动态图形不做「固定坐标=固定颜色」的点断言。** 旋转/缩放目标上任何固定像素的颜色都随时间变，硬断言必然假绿或误报（首帧角度≈0 恰好通过 = 最典型的假绿）。
2. **每个断言必须可复现。** 同一窗口连跑两次，断言结论必须一致；不可复现的断言视为无效门禁。
3. **像素断言证明「内容在不在、位置对不对、颜色对不对」，不证明「边缘形状/亚像素质量精不精确」。** 后者由 Golden 基线（同引擎逐位对比）+ 逻辑命中探针合证（§5）。
4. **任何视觉断言失败优先怀疑引擎洞，其次才是示例用法。** 判定「示例用法不对」必须给出布局链/变换链的实测证据，禁止凭印象归因。

## 2. 图形形态 × 断言方式矩阵（F0–F9）

> 每个 ui_wr_* 真窗按自己包含的形态逐行选型；同一目标多形态叠加时，各形态断言全部适用。

| # | 图形形态 | 特征 | 允许的断言 | 禁止的断言 |
|---|---------|------|-----------|-----------|
| F0 | **静态图形**（色块/格阵/面板） | 位置与颜色全程不变 | **精确点采样**：中心点 RGB 与基色比对（容差 ≤8/通道）；≥3 个采样点 | 无 |
| F1 | **平移动画**（位置变、形状不变） | 每帧 offset 不同 | **锚点采样**：从引擎布局链实时取当前 offset 再采中心；或区域占比（基色占比 ≥50%） | 固定坐标点采样 |
| F2 | **旋转动画**（绕中心转） | 边缘像素进出外接区 | ① **变换不变点**：中心点恒在图形内 → 精确采基色；② **区域占比区间**：固定外接区内基色占比 ∈ [理论下界−10%, 理论上界+5%]（如 45° 方块 ≈50% → [40%,55%]）；③ 占比骤降为 0 = 内容消失，最高优先 FAIL | 外接区角落采样；占比等值断言（必须区间） |
| F3 | **缩放动画**（呼吸/pulse） | scale 波动 [smin,smax] | 同 F2 两类：中心点（smin 仍保证中心在内）+ 占比下界按 smin² 折算（面积∝scale²）；上界按 smax² 折算 | 用满尺寸理论占比做等值断言 |
| F4 | **裁剪图形**（clip 内子内容溢出边界） | 可见部分 < 子内容 bounds | 「**裁剪外不可见**」（带外采样=背景色）+「**裁剪内可见**」（带内子内容基色占比 ≥ 预期可见比例×0.8）双断言 | 在被裁掉的区域找子内容颜色 |
| F5 | **半透明/混合图形**（opacity<1、SaveLayer 组、渐变） | 结果色 = 混合式 | 按 alpha 预公式算期望混合色再比对（容差 ≤12/通道，附公式）；渐变只断言两端点 + 中点单调方向 | 直接和源色比对 |
| F6 | **文字** | AA 边缘多、抗锯齿灰阶 | 区域级：文字包围盒内「非背景色像素数 ≥ 阈值」+ 主色占比；Golden 基线对比允许逐像素 | 单点采样（可能落在字间空隙）；无基线时逐像素比字形 |
| F7 | **细线条/边框**（1px 线、描边） | 亚像素覆盖、DPR 敏感 | 线段路径上采样多点，「至少 N 点显著偏离背景」即过；不要求纯色 | 线上任意单点必须等于线色 |
| F8 | **浮层/遮挡**（overlay panel、modal barrier） | 出现/消失改变下层可见性 | 双态断言：开→浮层基色占比 ≥ 阈值 且 被遮下层基色占比骤降；关→恢复。过渡帧（开合动画中）不采样 | 过渡帧上断言终态 |
| F9 | **异步到达内容**（图片解码完成、状态切换） | 到达时刻不定 | 到达后稳定 ≥3 帧才采样（用引擎事件/计数器同步，不用 sleep 定时）；到达前后双态各断言一次 | 固定时间点盲采 |

## 3. 采样纪律（所有形态通用 · 硬）

1. **采样时机**：只在相位轴上的已知稳定段采样（Steady 段、浮层完全打开后的平台期），避开相位切换帧、动画过渡帧、resize 后 3 帧内。动态目标的采样帧用**确定性相位时间**选定（对应 pumpFrames 语义），不用真实墙钟盲采。
2. **采样坐标来源**：一律取自引擎布局链实测值（body+offset 链），禁止手算硬编码坐标（§2.6.1 布局驱动规则的像素版）。坐标必须随 resize 自动跟随（布局驱动），resize 后断言仍成立。
3. **颜色容差（对齐 Flutter precisionTolerance 语义）**：
   - 默认**零容差仅适用于同引擎 Golden 基线对比**（GPU readback vs 上次留档 PNG，逐位一致或显式声明容差）。
   - 对**理论色**的比对（GPU 合成路径含 AA/混合/色彩空间舍入）：通道差 ≤8 视为一致；半透明/混合（F5）放宽到 ≤12 并须附混合公式；超出 = FAIL。
   - 容差必须在 README 写明依据，禁止无声明放宽（metrics-audit 按「阈值偷放」审查）。
4. **背景污染检查**：凡真窗引入临时视觉态（高亮/hover/debug 色），必须验证其**恢复帧**回到基色（C8 教训：highlight 叠加无恢复逻辑污染后续采样）。debug 重绘色验证遵循 R12b 的 on/off 双跑模式。
5. **快照纪律**：`SnapshotPath` 快照至少 2 张——稳态中段一张 + Recover 段一张（验证恢复后无残留）；快照随 JSON 一并留档；**连续两次运行的稳态快照做 Golden 式逐像素对比**（结构稳定区域应逐位一致，动态区域按形态矩阵判定），差异区产出差异图定位。

## 4. 门禁化（进 EvaluateGates · 硬）

- 像素断言结论必须写入 ability_extra（如 `pixel_static_ok` / `pixel_rot_ratio_ok` / `pixel_overlay_dual_ok` / `pixel_golden_diff_pct`），由 `EvaluateGates` 判定，**不允许只在示例里打印不进门禁**。
- 动态占比断言给区间不给等值；区间上下界必须在 README 写明推导依据（几何理论值 ± 容差）。
- 「内容消失」类失败（F2/F3/F8 占比→0）为最高优先 FAIL，任何其他门禁绿都不能抵消。
- Golden 差异率 `pixel_golden_diff_pct` 超过 README 声明的 tolerance 即 FAIL；未声明 tolerance 视为零容差。

## 5. 三证据合证（缺一不可 · 对齐 Flutter hitTestable + golden 双体系）

| 证据 | 证明什么 | 证明不了什么 | Flutter 对齐物 |
|------|---------|-------------|---------------|
| 逻辑命中探针（hitTest/scripted probes） | 行为身份对（点到谁是谁） | 内容是否真的画出来了 | `find.hitTestable()` + `hitTestInView` |
| §2.7 像素断言（点采样+区域占比+容差） | 内容在、位置对、颜色对、不被错误裁剪 | 边缘形状精度、亚像素质量 | `matchesSemantics` 级区域断言 |
| Golden 快照对比 + 留档 | 逐位回归防护、人眼复查、差异定位 | 首次运行（尚无基线） | `matchesGoldenFile` + compareLists |

三者合证才允许标 ✅；只有其一视为假绿风险，metrics-audit 有权判 FAIL。首次运行只产基线不定 PASS（golden 语义），第二次运行起才进入逐位对比门禁。

## 6. 反模式清单（出现即 metrics-audit FAIL）

- ❌ 对旋转/缩放目标的固定坐标点断言（首帧角度≈0 时恰好通过 = 假绿）
- ❌ 占比断言用等值而非区间
- ❌ 只在 Steady 首帧采样、后续相位无采样
- ❌ highlight/临时视觉态无恢复逻辑，污染后续采样点
- ❌ 手算固定采样坐标（不走布局链）
- ❌ 像素结果只打印不进 ability_extra 门禁
- ❌ 用 sleep 定时采异步内容（应同步引擎事件）
- ❌ 快照缺失或只有 1 张
- ❌ 无声明的容差放宽（Flutter precisionTolerance 语义要求显式声明 + 依据）
- ❌ 断言不可复现（连跑两次结论不一致）
- ❌ 把「示例用法不对」当结论却给不出布局链/变换链实测证据
