# 跨语言调用并批开发计划（并跨语言调用）

> 状态：A 期已完（2026-09-23，工作区待提交），B/C/D 待排期。目标：把每帧上百次 Go→C 显卡调用并成几次，
> 光栅从 16ms 往 12~13ms 走，余量拉到 3ms 以上，21~33ms 那档顿挫跟着消失。
> 只走标准做法，非标准的不要。

## 0. 背景（一句话）

- 25 秒鹈鹕剖析：跨语言门（`runtime.cgocall` + purego + `WriteBuffer/Draw/Set*`）占 44.6%，
  描边 Stroke 占 14.2%（模板构建 11%）。
- 已落地（54118e88）：模板填充 uniform 上 slab + cover 免传。单测绿，两时刻像素 0 差。
- 活窗现状：卡 1~6 次/25 秒、p95 约 17~28ms（机器状态波动大，单跑一次不定论）。

## 1. 目标与非目标

- 目标：同画面、同像素，跨语言调用次数降一个数量级；光栅均值进 13ms 以里；
  p95 回 22ms 门禁线以里；三窗（图标/鹈鹕/列表）都受益，以后组件库/2.5D 沾光。
- 非目标：不动画面、不动接口、不动 present 语义；视频贴图路不动（另立项）；
  虚线砖贴化不做（0.82% 原理差，非标准，已撤回）。

## 2. 范围（只动 `render/internal/gpu` 共用路）

- 在内：模板顶点 slab（扇形+包围盒+AA 带，打包一次上传，绘制报偏移）、
  描边指纹跳过（同形同色不重算，指纹命中直接复用上帧包）、
  绘制调用整编（同管线连画的 Set*/Draw 序列收敛，能省一次是一次）。
- 在外：示例层（`examples/` 只做验证）、调度与平台层（节奏已对齐标准）、
  present/swapchain 语义、视频解码与播放链路。

## 3. 对齐标准

- Slab 打包：照贴图路现成套路（256 对齐、增长带余量、旧板延迟退、管线重建换绑定）。
- 粘滞跳过：字节/指纹一样就跳过（浏览器/Skia 同款省法）。
- 内容频率跟显示器：已落地（Wayland 读 mode、X11 读 RandR），本计划不再动节奏。
- 非标准一律不要：贴砖配容差、写死频率、示例层绕引擎，全部不收。

## 4. 分期

| 期 | 内容 | 门禁 |
|---|---|---|
| A. 顶点 slab | 模板三顶点源（扇形/包围盒/AA 带，约 60 次上传）打包一次上传；绘制用 `SetVertexBuffer(offset)+Draw(firstVertex)` 报号；绘制次数不变（stencil 一路一画，省的是上传不是绘制），预期光栅降 1~2ms；旧板延迟退、epoch 换绑、失败帧不污染下帧 | 单测绿；两时刻像素 0 差；活窗对照不退化 |
| B. 描边指纹 | 同形同色描边指纹命中跳过重算重传；指纹键=形状哈希+颜色+矩阵，冲突当没命中走老路（宁多算一次不画错一像素），命中复用上帧包 | 同上 |
| C. 绘制整编 | 同管线连画的 Set*/Draw 序列收敛（已有账本/去重之上，能省一次是一次）；不动 stencil 语义 | 同上 + 全回归 |
| D. 收敛 | 注释说人话、抽公共函数、删重复分支；功能零改 | vet 干净（除存量）、格式干净 |

每期独立验证、独立提交（video 及别线一概不带，推送另行确认）。

## 5. 验证矩阵（每期必跑）

- 构建：`gofmt -l` 干净；`go vet` 无新增（存量 `unreachable code/unsafe.Pointer` 除外）。
- 单测：`render/internal/gpu` 全包 + `render` 包 + `ui/scheduler` + `ui/embedder`
  逐文件跑（禁止一次全量，参照既有纪律）。
- 像素：鹈鹕 T=5.0 与 T=12.0 两时刻 Golden，抽样 93600 点 0 差（容差显式声明）。
- 活窗：鹈鹕 25 秒 + 图标 15 秒 + 列表 15 秒，Wayland；记录 hitch/p95/p99/raster；
  机器状态波动大时做干净对照（撤掉改动重跑），不拿单次噪声下结论；
  每期人工看 1 分钟确认窜感（数只管帧间隔，眼管顺序感）。
- 文档：公开 API 有变才同步总账；否则修订表记一行。

## 6. 风险与兜底

| 风险 | 等级 | 兜底 |
|---|---|---|
| 顶点偏移错一位整屏花掉 | 高 | 逐像素门禁卡死；偏移计算单测先行；失败帧不污染下帧 |
| 板增长时在途命令野绑定 | 高 | 旧板延迟退（RetireBuffer）；绑定 epoch 对账 |
| 管线重建后绑定指向旧布局 | 中 | epoch 变化整批换绑；per-entry 布局检查保留 |
| 驱动对非零 Offset/Size 挑剔 | 中 | 只用已在线的偏移绑定画法（贴图路同款）；出问题整期回滚 |
| 活窗噪声误判优化无效 | 低 | 干净对照 + 多跑取稳态；噪声大时只认像素与单测 |

- 任何一期像素门禁不过：整期回滚，不带病合入。
- 工作区 video 及别线改动一概不碰；提交前 `git status` 对清单。

## 7. 受益面

- 直接：图标/鹈鹕/列表三窗 + 所有走 GPU 层画矢量的调用方。
- 将来：组件库、2.5D 引擎（走同层即沾光）。
- 不沾：视频解码与播放（贴图路，另立项）。
