# antd 组件开工流程（先流程后组件）

> 目标：每份 `docs/antd/*.md` 只看自己就能开工。2026-09-14 起 W0 文档与 W1 代码全推翻重写：先修门禁 → 再定 W0 文档 → 先立按钮标杆并签字 → 再铺开 W1；跳步必返工。

## 1. 开工前置（W0 地基，先行）

> W0 是开工波次（`W` = Wave）。各控件 §6.1 的 L1–L4 是验收档（行为/Token/截图/人眼），与 W 不冲突，见 §3。
> W0 重写落定（文档定稿 + 门禁修好 + 地基 5 项重验）前，W1 代码不开工，各控件 §6.12 第 5/6 条视为悬空，不算完成。

- 套件架子：新建 `ui/kit`，一控件一目录（如 `ui/kit/button/`、`ui/kit/select/`），各任务只改自己目录；根上放 `ui/kit/doc.go`（规矩）与 `ui/kit/coverage.go`（进度，见下）。文档旧称 `primitive/core` 不再新建，统一映射到现有 `ui/rendering` 等包；所有 §6.10 Go 签名落到 `ui/kit/<名>/`。
- 示例总窗：新建 `examples/ui_polish_gallery`，一个窗口、左标签（组件列表）、右展示（该组件页）。一控件一标签，能力按官方示例分 section；§6.8 P0+P1 一次做完，官方非 debug 一个不少（口径见 README 示例节）。每个标签须可独立打开、独立测、独立截图；总窗只作平时预览，正式验收以单标签独立断言为准（组合窗不代替单能力）。事件主干（悬停/按压/键盘/重画）接线待重验。
- 覆盖记录：位置 `ui/kit/coverage.go`，每控件一行 Notes：P0+P1 已对齐该 md §6 哪条，真做不了的单测 Skip 写清平台原因（写法照各控件 §6.12）。重写期间先以 README 看板为准，同步后再两处一致。
- 主题扩容：分两步。先补全局种子（对齐 antd v6.5.1：主色/文字/背景/边框、字号、间距、圆角、控件高度、内外边距、阴影、遮罩色），让 L2 断言有数可对；组件特有 Token 做到该组件时再补。全局种子里悬停/按压/内边距等派生 Token 还没跟官网种子对过数，重写期间先对数再开 W1。
- 浮层定位：在 `ui/overlay` 一次做通用能力（十二方向定位、贴边翻转、箭头跟随、外点关闭、焦点锁），对齐 antd 定位语义；各组件只调用不自写一套。重写期间按 antd 定位语义逐项重验一遍。焦点/手势复用现有 `ui/focus`、`ui/gestures` 包，不够再补；否则下拉、菜单、弹窗、抽屉、提示类做不出。

## 2. 文档就绪标准（每份必须同时满足）

1. 参数全：类型、默认值、版本齐，关键项在正文有绘制说明。
2. 示例全：非调试示例一个不漏，真做不了的单测 Skip 写清平台原因，不设分期去向。
   特性流程全：§6.9 开头必须有测试说明（特性与官网 demo 一一对应：测什么、
   怎么点、看什么效果），没这节不开工。
3. 度量有数：宽高行高边距圆角字号可断言，能映射到主题变量或回落常量。
4. 交互有状态机：规则编号化，只写适用的态，不套模板。
5. 平台边界写死：浏览器能力写明映射还是不做。
6. 接口用例可落地：Go 签名具体，用例一步一期望。
7. 截图有落点：官网基准截图的来源/版本/存放目录/签字去向按 README 截图基准节写齐，缺一项不开工。

## 3. 完成标准（单组件）

- §6.8 P0+P1 全实现（官方非 debug 一个不少）；§6.9 P0+P1/L1/L2 用例全过；L2 度量断言过；L3 showcase 大图 + 官网并排验收通过（含截图落盘与签字）；独立真窗 `examples/kit/<名>/` 已建且 `-auto-only` 按该组件特性流程逐功能验效果全绿；示例总窗中该标签页更新（可独立打开断言）；覆盖记录更新。
- 无分期：P0+P1 与非 debug 示例一次做完才算全完成（见 README 示例节口径）。
- 人测完才关：机器全绿只是待验，人必须跑真窗按该组件文档 §6.9 开头测试说明
  亲手测完窗内每个实例的每个功能并看效果（特性与官网 demo 一一对应，
  一项一效果），并在 §6.9 L4 留验收记录；没记录不许标完成，人没点头最多待验
  （见 ACCEPTANCE 第八节）。
- 开工三闸：门禁已改成 P0+P1 同查且三处回归全绿；W0 文档已定稿；W1 先过按钮标杆签字。闸没过就铺开，返工自负。

## 4. 级联依赖顺序（供后面并行用）

- W0：先修门禁（改成 P0+P1 同查）→ 重写 72 份文档 → 重验地基（§1 五项）→ 图标先行（最底层，多方引用）。W0 不落定，W1 不开工。
- W1（L1 无依赖基础件，先按钮标杆签字，再 18 个并行）：按钮先单做、官网并排签字定标杆，然后提醒、装饰光边、分割线、弹性盒、浮动按钮、栅格、布局、瀑布流、进度、骨架、间距、加载圈、分割器、统计、标签、时间线、排版、水印并行。波内先做加载圈/骨架，再做提醒/统计/时间线/标签。
- W2（L2 组合件，20 个并行）：固钉、头像、徽标、卡片、走马灯、折叠、描述、空态、菜单、提示、气泡、二维码、单选、评分、结果、分段、滑动、步骤、开关、页签。波内先做提示，再做气泡/分段。其中提示、气泡两件旧实现已做，因站在按钮和画廊上连带回炉，W1 落定后先回归再往下走。
- W3（L3 浮层表单件，18 个并行）：输入、选择、树、时间选择、自动完成、提及、数字输入、颜色、图片、消息、通知、漫游、锚点、下拉、气泡确认、上传 + 抽屉/弹窗本体（涉表单联调部分延后到 W4）。波内输入/选择先，再做自动完成/提及/数字输入/时间选择。
- W4（抬升件 + 聚合，11 个）：表单、多选、分页、日历完整头、面包屑完整下拉、列表、表格、穿梭、级联、日期、树形下拉 + W3 遗留的抽屉/弹窗表单联调。波内多选/分页先 → 表格/列表 → 穿梭；树 + 选择就绪 → 树形下拉/级联；输入 + 时间就绪 → 日期 → 表单。
- W5（L5 全局，最后，2 个并行）：应用、配置（等消息/弹窗/通知 + 按钮/输入全就绪）。
- 随时可并行：工具（无 UI，不进 kit，按 §6 做类型对照）。

波内可并行（各改各的 `ui/kit/<名>/` 目录），跨波必须等上游就绪；倒挂 6 处（弹窗/抽屉/多选等低波位等高波位）已抬到 W4，详见各控件 §2.7“等谁”行。
