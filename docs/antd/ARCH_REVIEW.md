# 组件架构三遍复核报告（从架构到任意组件是否成立）

> 目标：证明“用 Flutter 组件架构模型，能做出 antd 官方 1:1，且不限于 antd”。
> 方法：连梳三遍。版本：v1（2026-09-20），依据 `ARCHITECTURE.md` + `WIDGET_MODEL.md` + `F0_FOUNDATION_PLAN.md`，抽查 antd 6.5.1 官方示例与 API（button/input/select/table/modal/form/config-provider）。

## 第 1 遍：架构完整性（分层/三件套/主题/接线有没有死角）

结论：成立，无死角，但有 4 处“写了方向没写死规则”，在第 2 遍里现形，已列入 §5 补丁。

- 分层：L0 主题 → L1 基础件 → L2 行为件 → L3 产品 → L4 组合全局，依赖只许往下，产品禁直调 `render/gpu`、禁自写定位手势焦点。对应 Flutter `rendering` + `widgets/basic` + `material` 三层，无跨层口。
- 三件套：`<Comp>Props`（不可变，对标 `Widget`）/ `<Comp>Instance`（状态机，对标 `State`）/ Render 段（只拼，对标 `RenderObject`）+ `Ctx`（显式传参，对标 `InheritedWidget`）+ `StateResolver`（按状态取值，对标 `WidgetStateProperty`）+ 三级合并（对标 `ButtonStyle` 的自己 > 主题 > 默认）。构件互相不抢活。
- 接线：布局、手势、焦点、浮层、语义、动效、文本、图片，每条都指到现有引擎包（`ui/rendering`、`ui/gestures`、`ui/focus`、`ui/overlay`、`ui/animation`+`ui/scheduler`、`ui/textinput`+`ui/textbuffer`、`ui/io`），F0 只包不造。有真窗证据的（R0–R22、C0–C11、IME R1–R5）全部复用，不重测底层，只测接线。

## 第 2 遍：抽最难的 7 个端到端（任意组件是否成立）

### Button（B 类，标杆）：成立

Props（type/color/variant/size/shape/block/ghost/disabled/loading 含 delay、icon 前后、回调、语义逃生口）→ 主题三级换算（type 糖按 `ButtonTypeMap` 转 color+variant，显式 color/variant 优先）→ 状态机（hover/pressed/focus/disabled/loading，delay 未到不转，防重）→ 拼装（Decorated 包横排图标文字 + 动效波纹转圈）→ 焦点键盘语义。渐变示例走 Decorated 渐变（`render` 有线性/径向/扫掠，见渲染母表 FS-LINEAR/RADIAL/SWEEP），幽灵走透明底，圆形走形态 + 命中区跟随。无缺口。

### Input（C 类 + 输入法）：成立，有 1 条规则要钉死（见 §5-1）

受控（只回调不回写）/非受控（内部存）、清除调一次空值、禁用吞、只读可聚焦、超长截断、计数、错误边框、回车调搜索、密码显隐不改值、多行按行数定高 + 自动伸缩钳在最小最大行之间，全部能映射到 `Field` + 输入法会话（每窗编辑器 + 排版 + 会话，焦点驱动，无输入法降级）。缺口：拼音未上屏时值变算不算数——必须钉死“拼写中不调回调，以提交值为准”，否则搜索联想和计数器必乱。

### Select（C+D+虚拟+搜索）：成立，有 2 条要钉死（见 §5-2/3）

单选多选标签模式、搜索过滤、虚拟开关、最多选中数，映射为触发件（像输入框）+ 浮层下拉（Overlay 触发器）+ 虚拟列表（只建可见行）+ 标签行。缺口：键盘上下选回车定 Esc 关的顺序，以及标签太多时收起规则（官网有省略逻辑，不能各写各的）。

### Table（E 类）：成立，有 1 个组合范式要补（见 §5-4）

列配置、数据源、分页、行选、固定列头列、分组头、虚拟，映射为表头行 + 体视口（虚拟）+ 固定列（左右钉住）+ 分页条 + 行选框（复用 Checkbox）。缺口：固定列 + 横向滚动 + 虚拟 + 分页叠在一起时谁包谁，要给一个标准包法，不然每人拼出来不一样。

### Modal（D 类）：成立，有 1 个宿主设计要补（见 §5-5）

受控显隐、空脚自定义脚渲染函数、确定加载、动画后回调、命令式确认框 + 销毁全部，映射为浮层（居中遮罩）+ 焦点圈地（Tab 不出框、Esc 关）+ 动画 + 宿主（App 级的弹框栈，命令式调用往栈里压）。缺口：Go 没有 React 上下文，命令式确认框的宿主放哪、层叠谁管，要点名。

### Form（F+E）：成立，有 1 条时机要钉死（见 §5-6）

字段注册、规则校验、提交重置、联动，映射为字段表（`Field` 注册）+ 校验链（时机：改时/失焦/提交可配，异步校验要防竞态先到后到）+ 错误展示 + 滚到首错。缺口：校验时机和异步顺序现在没写死。

### ConfigProvider/App（F 类）：成立

尺寸禁用语言主题动效全局下发 = 往 `Ctx` 里放东西，换肤切尺寸整树禁用一处改全局生效。无缺口。

## 第 3 遍：超 antd（不限于此库是否成立）

成立，理由：`prim/behavior/scope` 都是通用的，不带 antd 味。换一套 Token + 另一套 Props，就是另一套组件库（比如自研库、图表库、甘特图、组织架构图），照样拼。换肤 = 换主题实例重跑合并；RTL = 切 `Dir` 重排（图标前后、分页箭头、方向边距圆角）；性能 = 独立重画 + 缓存预算 + 虚拟化三板斧，哪个库都一样。限制只有一条：自定义绘制走 `CustomPaint` 门面，不许绕过 Layer 直触 GPU（引擎真源 §1.2）。

## 5. 本次补丁（已落 `WIDGET_MODEL.md`，其余进 F 类/E 类计划）

1. 拼写中不调回调（C 类铁律）：`composing` 期间显示拼写串，`Value()` 读提交值，`onChange` 只在提交时调一次。
2. 下拉键盘顺序： closed→Enter/Space/Down 开 → Up/Down 移 → Enter 定 → Esc 关；焦点始终在触发框，选项只高亮不抢焦点。
3. 标签收起：多选标签按 `maxTagCount` 收起 + 省略号，收起数标在尾标签，读屏读全量。
4. 表格标准包法：分页条在外、视口在中、固定列钉在视口两侧、虚拟只管体行；横滚时头跟体同滚，固定列不动。
5. 弹框宿主：`App` 级 `ModalHost`（栈 + 层叠 + 销毁全部），命令式确认框只许调它，不许各组件自建浮层栈。
6. 校验时机：`validateTrigger`（改时/失焦/提交）+ 异步防竞态（后发先到以末次为准，先到的结果丢弃并记日志）。

## 6. 结论

从架构到任意组件成立，1:1 能做，不限于 antd。上述 6 条是本次复核唯一的增量规则，无结构性返工；旧 `ui/kit` 实现仍作废，不影响结论。
