# video_vc2_soak — VC2 120秒长跑组合窗（VR4播放 + VR7极限）

跑法（关闭用 120 秒）：

```bash
export LD_LIBRARY_PATH=$PWD/lib WGPU_NATIVE_PATH=$PWD/lib/libwgpu_native.so
RUN_SECONDS=120 go run ./examples/video_vc2_soak
```

## 人眼可见效果

- 左边五站：同片 1080p 出数——拆盒（1920x1080/5fps/5采样/关键帧≥1）、参数（档位/等级/片头图参数/切帧/IDR）、冷解码（5帧均值/p95+显示序递增）、转色（首尾帧 MAD 非黑+播完零丢）、封顶（三池就绪+预估远小于512MB）。任一站红整窗红。
- 右边直播：同片 1080p 循环 120 秒，画面一直动，不黑不花；每帧黑检测走工作池（借-拷-算-还），池命中 HUD 可见。
- 底部 HUD：fps/解码/队列/内存四曲线，外加分配+池+GC。

## 门禁

- 长跑播稳 `soak_ok=1`：直播>0 帧且尾 MAD≥2（池工作输出即黑检测，黑住/定住直接红），否则 `FAIL:` + `exit 1`。
- 五站全过：1920x1080 写死校验（降档偷过直接 FAIL）、冷解码播到 Ended、显示=解码=采样、零丢、显示序递增、首尾 MAD≥2、预估<512MB，否则挂。
- 稳态分配≤2048字节/帧：开窗前独立探针测 video 核心稳态（池预热+新循环播放器预热后 5 秒 Poll+池工作，GC 净底，堆增量/稳态帧数；UI 渲染/HUD 与 GPU 建窗全部排除在外），超了挂。
- 工作池命中≥90%，泄漏（借未还）=0，否则挂。
- 内存峰值≤512MB（1080p 档封顶），斜率≤30000KB/分钟，超了挂。
- GC 停顿 p99≤10毫秒，CPU 均值≤85%，否则挂。
- 卡顿率≤5/分钟（§2.2.2 长跑默认线；同盒 VR7 60秒实测 0/分钟，同片同上传路径，默认线即诚实线，不沿用 VR7 首跑的宽松值），超了挂。
- 动画窗 60 档：`fps_wall≥55` 且 `interval_p95_ms≤22`，否则挂。
- §2.2 全族 JSON 打到 stdout，缺键就挂。支持 `BASELINE_JSON` / `SAVE_BASELINE_JSON` 回归。
- 首帧超 2000 毫秒挂。
- 只做长跑集成回归，不代替任何单能力窗；优化后 VR2/VR3 门禁重跑不回退（见提交说明）。
- 斜率口径说明：120秒窗的 `rss_slope` 含 UI 渲染/HUD 的堆涨（首跑 22049KB/分，起 233MB 到 394MB，峰值 413MB<512MB），video 核心稳态另由开窗前独立探针量（89B/帧）——两笔账分开算，混在一起会把 UI 的涨算到解码头上，VR7 已证伪过一次。
